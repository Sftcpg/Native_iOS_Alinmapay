## Installation

iOS_Hosted_plugin is available through [CocoaPods](https://cocoapods.org). To install
it, simply add the following line to your Podfile:

``` ruby
    pod 'Ios_alinmapay', '1.0.0'
```
**Note:** CocoaPods integration remains supported.
